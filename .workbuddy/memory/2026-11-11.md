## 排查：双击 HTML 打开后内容显示不全

- 现象复现（无头 Edge + 截图）：`file://` 打开 `index.html` 只剩 hero，卡片全空白。
- 根因：`css/cards.css` 中 `.card { opacity: 0; transform: translateY(24px) }`，卡片靠 `js/cards.js` 的 anime.js 入场动画显形；而两个 HTML 底部是 `<script type="module" src="js/main.js">`，`file://` 下模块脚本被 CORS 拦截（origin 'null'），JS 全不执行 → 卡片永久隐藏。
- 第二个坑：即使用普通静态服务器（`python -m http.server`）也不行，`cards.js` / `score.js` 里 `import ... from "animejs"` 是裸模块名，浏览器无法解析；必须走 Vite（`npm run dev`）做依赖预构建。`http://127.0.0.1:5173/index.html` 下已验证页面完整。
- 顺带发现的既有 bug：`js/score.js` 使用了 `scrambleText` 但没有 import（只导入 animate/stagger），点「开始分析」会报 ReferenceError；`src/*.jsx`（React 版 ResultCard）目前没有任何 HTML/入口引用，属后续课件素材。
- README.md 第 21 行仍写「双击 index.html 即可」，与第 149 行「模块化后别再双击」矛盾，是过时说明，容易误导。
- 本次仅诊断，未改动任何源码；已告知用户并等待是否修复的确认。
